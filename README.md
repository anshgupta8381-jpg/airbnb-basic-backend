# airbnb-basic-backend
A full-stack Airbnb-inspired rental app built with Node.js, Express &amp; EJS. Hosts can list/edit/delete properties. Users can browse homes &amp; manage favourites. MVC architecture with file-based JSON storage.
# 🏠 Airbnb backend basic project

> A full-stack home rental platform where hosts list properties and guests discover & book their perfect stay.

## ✨ Features

- 🏡 **Host Dashboard** — Add, edit, and delete your listed properties
- ❤️ **Favourites** — Save and manage homes you love
- 📋 **Browse Listings** — Explore all available homes with photos, pricing & location
- 📱 **Responsive UI** — Clean card-based layout that works on all screens

## 🛠️ Tech Stack

![Node.js](https://img.shields.io/badge/Node.js-339933?style=flat&logo=nodedotjs&logoColor=white)
![Express.js](https://img.shields.io/badge/Express.js-000000?style=flat&logo=express&logoColor=white)
![EJS](https://img.shields.io/badge/EJS-B4CA65?style=flat&logo=ejs&logoColor=black)

- **Backend** — Node.js + Express.js
- **Templating** — EJS
- **Storage** — File-based JSON (no database)
- **Routing** — MVC Architecture
